# AiSpace — сервис бронирования переговорных комнат

Внутренний сервис: видно занятость комнат, можно забронировать слот, в том числе
фразой на естественном языке через DeepSeek. Есть админка (комнаты и пользователи)
и удобная клиентская часть с допами к броням (вода, кофе, проектор и т.п.).

## Стек

- **Backend:** Python + FastAPI (async), SQLAlchemy 2 (asyncpg), Alembic
- **Frontend:** React + Vite + TypeScript (раздаётся через nginx)
- **БД:** PostgreSQL 16 (только в контейнере)
- **Auth:** JWT (bcrypt для паролей)
- **NL-разбор:** DeepSeek API
- **Инфраструктура:** Docker Compose (db + backend + frontend)

## Архитектура (backend)

Слоистая: каждый слой зависит только от нижнего.

- `core/` — инфраструктура: конфиг из `.env`, async-подключение к БД, безопасность (пароли/JWT).
- `models/` — ORM-модели (таблицы): `User`, `Room`, `Booking`.
- `schemas/` — Pydantic-DTO: контракт API отдельно от структуры БД.
- `services/` — бизнес-логика: проверка конфликтов броней, интеграция с DeepSeek.
- `api/routes/` — тонкий HTTP-слой: валидация → вызов сервиса → ответ.

## Принятые решения (трактовка неоднозначностей)

- **Непересечение броней гарантирует БД, а не код.** В PostgreSQL стоит
  `EXCLUDE USING gist (room_id WITH =, tstzrange(start_time, end_time) WITH &&)`.
  Это исключает гонку двух одновременных запросов, которая осталась бы при проверке
  «SELECT → INSERT» в приложении. Конфликт → HTTP 409.
- **Роли: `user` и `admin`.** Обычный сотрудник бронирует/отменяет только свои брони;
  админ управляет комнатами и может отменить любую бронь.
- **Комнаты заводятся сид-данными при старте.** Набор переговорных (большая, малая и т.п.)
  заливается автоматически, чтобы сценарий проходился сразу; далее админ управляет ими в UI.
- **Удаление комнаты — мягкое (архив).** DELETE ставит `is_active=false`: комната пропадает
  из списка и бронирования, но история броней сохраняется, комнату можно вернуть.
- **Допы к брони — фиксированный каталог в коде.** Набор небольшой и редко меняется; в брони
  хранятся только id допов, каталог с иконками отдаётся через `GET /amenities`.
- **Управление пользователями с защитой.** Админ меняет роль и блокирует/разблокирует
  пользователей, но не может изменить или заблокировать самого себя (защита от потери доступа).
- **NL-бронь — через черновик с подтверждением.** DeepSeek возвращает распознанные поля,
  интерфейс показывает предзаполненную форму; пользователь проверяет и подтверждает.
  Так при неоднозначной фразе или недоступности сервиса нет «магических» неверных броней.
- **Время хранится в UTC (`timestamptz`).** Часовой пояс офиса задаётся в конфиге и
  используется при разборе фраз вида «завтра в 14:00».

## Запуск

Нужен только установленный Docker.

```bash
cp .env.example .env      # заполнить значения (пароль БД, JWT_SECRET, DEEPSEEK_API_KEY)
docker compose up --build
```

После старта контейнер бэкенда сам: ждёт готовности БД → применяет миграции
(`alembic upgrade head`) → сидит комнаты и админа → поднимает API. Ручных шагов нет.

- Веб-интерфейс: http://localhost:5173
- API: http://localhost:8000
- Swagger (интерактивная документация): http://localhost:8000/docs
- Health-check: http://localhost:8000/health

## Тесты

pytest против реального PostgreSQL (отдельная БД `<db>_test`, схема — через миграции
Alembic, чтобы проверять в т.ч. EXCLUDE-constraint по-настоящему):

```bash
docker compose run --rm --entrypoint pytest backend
```

Покрыто (27 тестов): аутентификация, конфликт пересечения броней (409) и стык (201),
валидация допов, мягкое удаление комнат, контроль доступа к админ-эндпоинтам,
управление пользователями (роли, защита от самоблокировки), история и аналитика.

## Веб-интерфейс (страницы)

- **Занятость** (`/`) — комнаты по выбранному дню, с допами и комментариями броней.
- **Забронировать** (`/book`) — форма + бронь фразой (NL), выбор допов, комментарий.
- **Мои брони** (`/my`) — предстоящие и прошедшие, отмена.
- **Админ · Комнаты** (`/admin/rooms`) — создание, редактирование, архив/возврат.
- **Админ · Пользователи** (`/admin/users`) — роли, блокировка, число броней.
- **Админ · История** (`/admin/bookings`) — все брони по датам со всеми характеристиками, фильтры.
- **Админ · Аналитика** (`/admin/analytics`) — метрики, активность по дням, топы комнат/пользователей/допов.

## Реализовано (backend)

- Аутентификация: регистрация, вход (JWT), `/auth/me`. Роли `user`/`admin`.
- Комнаты: список, создание, редактирование (PATCH), мягкое удаление (архив).
- Пользователи (админ): список с числом броней, смена роли, блокировка.
- Брони: создание с комментарием и допами, занятость с фильтрами, «мои брони», отмена.
- Допы: фиксированный каталог, `GET /amenities`, валидация id при создании брони.
- История броней (админ): `GET /bookings/all` — все брони с автором и комнатой, фильтры.
- Аналитика (админ): `GET /analytics` — метрики, активность по дням, топы.
- Непересечение — EXCLUDE-ограничение PostgreSQL, конфликт → HTTP 409.
- NL-бронь: `POST /nl/parse` — фраза → черновик через DeepSeek; отказ сервиса → 503.

## Эндпоинты

| Метод | Путь | Кто | Назначение |
|------|------|-----|-----------|
| POST | `/auth/register` | все | регистрация |
| POST | `/auth/login` | все | вход, выдаёт JWT |
| GET | `/auth/me` | auth | текущий пользователь |
| GET | `/rooms` | auth | список комнат (`?include_inactive=true` — админ) |
| POST | `/rooms` | admin | создать комнату |
| PATCH | `/rooms/{id}` | admin | изменить комнату |
| DELETE | `/rooms/{id}` | admin | архивировать (мягкое удаление) |
| GET | `/users` | admin | список пользователей с числом броней |
| PATCH | `/users/{id}` | admin | сменить роль / заблокировать |
| GET | `/amenities` | auth | каталог допов |
| POST | `/bookings` | auth | создать бронь (title, comment, amenities, время) |
| GET | `/bookings` | auth | занятость (фильтры: room_id, date_from, date_to) |
| GET | `/bookings/all` | admin | история всех броней (автор, комната, фильтры) |
| GET | `/bookings/my` | auth | мои брони |
| GET | `/analytics` | admin | сводная аналитика по броням |
| DELETE | `/bookings/{id}` | auth | отменить (свою; админ — любую) |
| POST | `/nl/parse` | auth | разобрать фразу в черновик брони |
